# College Event Site

This folder contains the HTML, CSS and JavaScript for the IEM CSE (AIML) college events website.

## Run locally
Open `index.html` in a browser. No installation or build step is required.

## Upload to GitHub
1. Create a new repository on GitHub.
2. Extract this ZIP file.
3. Upload the contents of the `college-event-site` folder (not the ZIP itself) to the repository.
4. Keep `index.html` at the repository root and keep the `css` and `js` folders.
5. To publish with GitHub Pages, open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.

## Important note
The original HTML links to `css/style.css` and `js/script.js`. The files are placed in those folders here so those links work. Root-level copies of `style.css` and `script.js` are also included to match the original repository's file listing.

The registration and feedback forms currently perform front-end validation only; they do not store submissions or actually send email. Replace the sample event dates, contact details and coordinator names with verified information before publishing.
